# ❤️ Heart Disease Prediction

A Machine Learning classification project that predicts the presence of heart disease based on patient health-related features.

In this project, multiple Machine Learning classification algorithms were trained and evaluated. The models were compared using appropriate evaluation metrics, and the **best-performing model based on the evaluation results** was selected for the final prediction application.

The final trained model is integrated with a **Streamlit** web application for interactive heart disease prediction.

---

## 🚀 Features

* ❤️ Heart disease prediction using Machine Learning
* 🤖 Multiple classification algorithms
* 📊 Model performance comparison
* ⚙️ Data preprocessing and feature scaling
* 🏆 Selection of the best-performing model based on evaluation metrics
* 💾 Saved trained model and preprocessing objects using Joblib
* 🖥️ Interactive Streamlit web application
* ⚡ Real-time prediction

---

## 🤖 Machine Learning Models

The following classification algorithms were implemented and compared:

* **K-Nearest Neighbors (KNN)**
* **Logistic Regression**
* **Support Vector Machine (SVM)**
* **Decision Tree**
* **Naive Bayes**

After training and evaluating the models, the model with the most suitable evaluation performance was selected for the final application.

## 🔬 Model Selection

Instead of directly using a single algorithm, this project follows a **model comparison approach**.

Multiple classification algorithms were trained on the same dataset and evaluated using consistent evaluation procedures.

```text
KNN
        │
Logistic Regression
        │
SVM
        ├──→ Model Evaluation → Model Comparison → Final Model
        │
Decision Tree
        │
Naive Bayes
```

The selected model was then saved using **Joblib** and integrated into the Streamlit application.
